# Week 2 Node Express API

## Description

This is my Week 2 backend development assignment.
It is built using Node.js and Express.

## Features

- GET / - Displays My Week 2 API!
- POST /user - Accepts name and email.
- GET /user/:id - Displays a user profile.
- JSON request handling.
- Request logging middleware.
- Error handling and validation.
- Static HTML page.

## Installation

1. Clone the repository.
2. Run npm install.
3. Create a .env file.
4. Add PORT=3000 to the .env file.
5. Run npm run dev.

## Technologies

- Node.js
- Express
- JavaScript
- dotenv
